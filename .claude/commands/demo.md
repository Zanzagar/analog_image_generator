Information about running the interactive demo.

The main interactive demo is in: `notebooks/v20a_interactive_rebuild.ipynb`

To run:
1. Start Jupyter: `jupyter notebook` or `jupyter lab`
2. Open `notebooks/v20a_interactive_rebuild.ipynb`
3. Run all cells to launch `ui.build_live_fluvial_panel(...)`

The panel includes:
- Style selector (meandering, braided, anastomosing, stacked)
- Style-aware parameter sliders
- Overlay toggle for additional facies
- Single preview and batch grid modes
- Metrics display (variogram, PSD, topology)

Demo script and talking points: `docs/MEETING_RECAP_2025-11-21.md`
